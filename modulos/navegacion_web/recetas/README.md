# Recetas reutilizables — Navegación Web

Scripts que **ya funcionaron** y quedan guardados para reutilizar. Los guarda el
módulo automáticamente (o con `registro.py receta ...`).

- Cada receta es un `.py` autocontenido y documentado.
- El índice está en `indice.json` (descripción + palabras clave + fecha).
- **Nunca** guardar credenciales, cookies ni tokens aquí.
- Uso personal/académico; respetar los términos de los sitios.
